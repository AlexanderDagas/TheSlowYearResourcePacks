# TheSlowYear resource packs

Public, immutable resource-pack downloads used by The Slow Year server.

- `MyFurniture_Pack.zip` supplies furniture models and textures.
- `ExecutableItems_Pack.zip` supplies ExecutableItems assets.
- `SeasonalWeather-Java-Clouds-1.0.0-mc1.21.11-rp75.zip` supplies dense
  vanilla clouds for Java 1.21.11.
- `SeasonalWeather-Java-Clouds-1.0.0-mc26.1.2-rp84.zip` supplies dense
  vanilla clouds for Java 26.1 through 26.1.2.
- `SeasonalWeather-Java-Clouds-1.0.0-mc26.2-rp88.zip` supplies dense
  vanilla clouds for Java 26.2.

The SeasonalWeather server plugin selects exactly one cloud overlay per Java
client protocol. Bedrock clients receive the separate Geyser-compatible pack.
